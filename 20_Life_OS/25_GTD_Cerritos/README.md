## 🛸 The Vessel: USS Cerritos [California Class]
*   **Mission**: Second Contact. Handling the grunt work. Clearing the Inbox.
*   **Officer**: **[A1] Ensign Mariner** (The Chaos).

## 🧭 The Framework: GTD (Getting Things Done)
The Cerritos handles the "Stuff" that flies at the windshield:
1.  **Capture**: Write it down. (Mariner's Datapad).
2.  **Clarify**: Is it actionable? (Boimler's Logic).
3.  **Organize**: Put it where it belongs.
4.  **Reflect**: Weekly Review.
5.  **Engage**: Do it.

## 📜 The Protocols
*   **Inbox Zero**: The daily goal.
*   **2 Minute Rule**: If it takes < 2 mins, do it now. Don't log it.
*   **Waiting For**: Track delegated tasks.
